# Reproducing hadronic `pp -> Z + j` with conditional normalizing flows

This folder is a self-contained snapshot of two projects, curated for one
purpose: reproducing the **Z + 1 jet** results.

| folder | contents |
|---|---|
| `conditional-nf-integration/` | the conditional normalizing-flow engine, the MadGraph integrand, the training and validation drivers, the LHAPDF convolution, and the six-channel Z+1 configs |
| `madgraph_test/` | exact MadGraph partonic scans, native `p p -> Z j` samples, lab-frame acceptance analysis, verification scripts, and the report |
| `lhapdf-local/` | the Windows LHAPDF ctypes shim and its C++ source (optional; use a normal LHAPDF install elsewhere) |

Large artefacts are deliberately **not** included: the generated MadGraph
standalones, the 12 trained checkpoints, and the native LHE event files.  They
are regenerated by the commands in [`RUNBOOK.md`](RUNBOOK.md).  The small
summary tables needed for the analysis are included.

## Main result (13 TeV, fixed scale 91.188 GeV, alpha_s = 0.130)

| quantity | value | source |
|---|---:|---|
| native `p p > Z j` (MadEvent) | **9142.3 ± 6.8 pb** | `madgraph_test/FINDINGS.md` |
| exact partonic + LHAPDF, per-channel lab acceptance | **9142.25 pb** | `verification/channel_acceptance.py` |
| conditional NF + LHAPDF, lab frame | **9155.14 ± 8.92 pb** | `verification/apply_lab_frame_nf.py` |
| NF / native | **1.00140** | |

The full derivation, definitions, bugs, and fixes are in
[`madgraph_test/FINDINGS.md`](madgraph_test/FINDINGS.md).  Supporting audits:
[`VERIFICATION.md`](madgraph_test/verification/VERIFICATION.md) and
[`NORMALIZATION_GAP.md`](madgraph_test/verification/NORMALIZATION_GAP.md).

The two frame issues that dominate the analysis are worth stating up front:

1. The `|eta| < 2.5` cut is applied in the **lab** frame by MadGraph but in the
   **partonic CM** by the NF.  The boost is not negligible; the conversion
   factor `A = sigma_lab / sigma_CM` is applied per channel and per
   sqrt(s-hat).
2. The native baseline uses the LO set `NNPDF23_lo_as_0130_qed` (LHAPDF ID
   **247000**, MG5's `nn23lo1`).  ID 230000 is a different (NLO) set.

## Quick start: reproduce the headline without retraining

Dependencies: Python 3.10, numpy, scipy, pandas, matplotlib, torch, and LHAPDF
6 with the `NNPDF23_lo_as_0130_qed` set.  The Windows shim in `lhapdf-local/`
is used only if no installed `lhapdf` module is found.

```bash
python -m pip install -r requirements.txt
export LHAPDF_DATA_PATH=/path/to/lhapdf/share/LHAPDF   # e.g. from conda
python reproduce_headline.py
```

`reproduce_headline.py` reads the packaged NF interpolation tables and the
saved acceptance table; it needs no checkpoints, MadGraph build, or event
files.  It prints the per-channel contributions and the final
**9155.14 ± 8.92 pb**.

## Full reproduction

[`RUNBOOK.md`](RUNBOOK.md) gives the complete chain:

1. install MG5 3.6.7 and LHAPDF, generate the six-subprocess standalone
   (`configs/processes/zj_hadronic_low.json`);
2. train the 12 balanced models (6 channels x low/high range);
3. validate NF against uniform Monte Carlo and against exact MadEvent at fixed
   sqrt(s-hat);
4. convolve the partonic cross sections with the LHAPDF luminosity;
5. apply the lab-frame acceptance and the threshold/tail corrections.

## What is included

- All Python modules required to generate, train, validate, and integrate the
  Z+1 models.
- The six-channel configs `zj_hadronic_low.json`, `zj_hadronic_high.json`.
- The NF interpolation tables (`interpolation_low/high.csv`) and the
  per-channel MadEvent comparison CSVs.
- The analysis tables: no-eta fine scan, lab/CM acceptance, per-channel
  integrands, NF lab acceptance, threshold scan, and the cached CM-fail ratio.
- The main report (`FINDINGS.md`), the method document (`PRD.md`), the
  verification audits, and the MadGraph generation cards.

## A caveat that matters

An older `results/zj_hadronic_integral/summary.json` reported 13765.5 pb.
That value predates the `xfxQ` -> `xfxQ2` fix (it passed `Q^2` to a function
expecting `Q`) and is **not** included here.  The corrected partonic-CM total
is **11752.44 pb**; the lab-frame result is **9155.14 pb**, produced by
`verification/apply_lab_frame_nf.py`.  See `FINDINGS.md` §7-§8.  Do not quote
13765.5 pb as the NF prediction.
